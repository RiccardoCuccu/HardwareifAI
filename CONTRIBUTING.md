# Contributing

This project recognizes five kinds of contribution, tracked as labels on Issues and PRs:

- `contribution: research` - adds papers.
- `contribution: industry` - adds job requirements.
- `contribution: education` - improves explanations.
- `contribution: engineering` - adds implementations.
- `contribution: review` - validates quality.

## How to contribute

**Proposing something** (a paper, a question, an idea): open an Issue. Go to the "Issues" tab on the repo page and click "New issue".

**Submitting a change**: open a Pull Request. Fork the repo, make your changes on a branch in your fork, then open a PR against `main`.

**Applying a label**: when creating or viewing an Issue or PR, use the "Labels" field in the sidebar to pick the contribution type that fits.
