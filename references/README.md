# References

The reference hub: bibliographic entries cited across the curriculum, plus a few independently curated lists.

## Contents

Auto-generated from every module's inline citations by `scripts/generate_bibliography.py`. Each of these files has three parts: a hand-owned preamble (H1 title + one-line description) that the script never touches, a `## Bibliography` section the script fully owns and rewrites on every run, and a hand-curated `## Extra` section the script never overwrites:

- [`papers.md`](papers.md) - cited scientific papers.
- [`repositories.md`](repositories.md) - cited code and model repositories.
- [`books.md`](books.md) - cited books.
- [`articles.md`](articles.md) - cited articles, blog posts, and announcements.
- [`courses.md`](courses.md) - cited courses and open courseware.

Curated manually, not touched by the script:

- [`benchmarks.md`](benchmarks.md) - benchmarks used to evaluate AI-accelerator hardware.
- [`companies.md`](companies.md) - companies working on AI-accelerator hardware.
- [`conferences.md`](conferences.md) - conferences relevant to AI-accelerator hardware design.
