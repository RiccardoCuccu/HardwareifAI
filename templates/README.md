# Templates

Standardised, reusable shapes so every paper review, project write-up, module, and Decision Log entry looks the same regardless of who wrote it.

## Contents

- [`module_template.md`](module_template.md) - shape for a module's `module_design.md`; fields defined in [`methodology/module_design_methodology.md`](../methodology/module_design_methodology.md) and [`methodology/topic_selection_framework.md`](../methodology/topic_selection_framework.md).
- [`project_template.md`](project_template.md) - shape for a hands-on project write-up; fields defined in [`methodology/project_design_methodology.md`](../methodology/project_design_methodology.md).
- [`paper_review.md`](paper_review.md) - shape for a paper review entry; fields defined in [`methodology/paper_selection_criteria.md`](../methodology/paper_selection_criteria.md).
- [`decision_log.md`](decision_log.md) - shape for a single Decision Log identity-card entry.

No particular reading order; each template is used independently as the corresponding content type gets created.
